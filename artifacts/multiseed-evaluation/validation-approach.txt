Evaluation reports two distinct strata across independent seeds. Held-out stress evaluation uses joint observation combinations absent from the training catalogue; in-distribution evaluation samples the training scenario catalogue using independent evaluation seeds. Both freeze Q-table updates and exploration, while allowing proposed-agent memory and affect to adapt online. Mean reward per step summarises the synthetic interaction objective; completion rate checks task outcomes; learning curves show changes during training. The diagnostic_one_step_oracle_agreement_rate is agreement with the exact Q* oracle for a separate one-step diagnostic MDP whose next state is terminal. It is not optimal-policy agreement for the full multi-step environment. These synthetic metrics validate implementation and policy learning only, not perceived believability, which requires separate participant ratings and behavioural analysis.
