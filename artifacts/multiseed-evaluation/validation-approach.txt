Validation uses paired baseline/proposed runs with the same held-out scenario combinations and a fixed latent simulated-user profile within each run, shared by both agents. Evaluation freezes Q-table updates/exploration while allowing proposed-agent memory and affect to adapt online. Mean reward per step summarises the synthetic interaction objective while completion rate checks task outcomes; learning curves show whether training performance changes over episodes. Policy agreement is measured against the exact one-step Q* oracle for a separate diagnostic MDP whose next state is terminal; it is not claimed to be the optimal policy for the full multi-step environment. These synthetic metrics validate implementation and policy learning only. They do not establish perceived believability, which requires separate participant ratings and behavioural analysis.
